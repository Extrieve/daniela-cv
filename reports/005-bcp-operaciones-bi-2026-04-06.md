## A) Resumen del Rol

El puesto de **Analista de Operaciones BI** en el Banco de Crédito BCP (banco líder del sistema financiero peruano) tiene como objetivo garantizar la disponibilidad y calidad de los datos en la plataforma de inteligencia empresarial, asegurando que los procesos de BI y Big Data operen de forma eficiente. Las responsabilidades incluyen mantenimiento de herramientas y bases de datos, seguridad de la información, optimización continua de plataformas, análisis de datos operacionales para identificar patrones, y generación de reportes de avance. El rol está clasificado en Tecnología de la Información, requiere grado universitario en carreras de sistemas y mínimo 2 años de experiencia en roles similares. Ofrece contrato en planilla permanente, bonos, participación en utilidades y horario flexible. **Importante:** la publicación data de hace 2 años (ya no recibe postulaciones activas), lo que reduce su utilidad inmediata pero sirve como referencia de perfil BCP.

## C) Estrategia

**BCP contexto:** Es el banco más grande del Perú (#1 en activos, utilidades y penetración de mercado). Su área de tecnología compite con estándares regionales — los procesos de selección son rigurosos, con pruebas técnicas y entrevistas por competencias. Un perfil que supere el filtro debe demostrar solidez técnica desde el inicio.

**Recomendaciones estratégicas:**

1. **Llenar el gap de Linux primero.** Es el único requisito marcado como obligatorio en la JD. Daniela puede completar "Linux for Beginners" (Coursera/freeCodeCamp) en 2-3 semanas y añadirlo al CV con fecha. Sin esto, la candidatura no pasa filtro técnico inicial.

2. **Migrar al menos un proyecto de Tableau a Power BI.** BCP usa el ecosistema Microsoft (Azure, SSMS, DataFactory) — Power BI es el estándar real. Recrear el dashboard de KAT Manufacturing en Power BI y documentarlo en el CV reemplaza o complementa la mención de Tableau.

3. **Reencuadrar Smart Perú como "operaciones de datos."** Evitar el título "Coordinadora Administrativa." El énfasis debe ser: gestión de plataforma de datos institucional, automatización de reportes, administración de DBMS, y análisis para toma de decisiones — lenguaje que resuena con la JD.

4. **SQL como fortaleza central.** BCP lista Oracle, SSMS y MySQL. El proyecto Hospital DB es concreto y demostrable. Preparar para prueba técnica de SQL (subconsultas, window functions, optimización de queries).

5. **Carta de presentación BCP-específica.** Mencionar conocimiento del contexto financiero peruano, disposición a aprender el stack tecnológico BCP, y el valor del perfil bilingüe (EN/ES) para coordinación con equipos regionales.

## F) Stories STAR + Reflexión

### STAR 1 — Mantenimiento de disponibilidad de datos (alineado con responsabilidad core del JD)
- **Situación:** En Smart Perú, el DBMS institucional era el único registro centralizado de activos tecnológicos y personal (~150 colaboradores).
- **Tarea:** Garantizar disponibilidad continua de datos para reportes a Vicepresidencia, operando en modalidad mixta (parcialmente remota desde EE.UU.).
- **Acción:** Establecí rutinas de actualización periódica, validé integridad de datos con controles en Excel, y generé dashboards ejecutivos para decisiones de dirección.
- **Resultado:** Cero interrupciones reportadas en ciclo de reportería durante 19 meses; confianza de la dirección para operar con plena autonomía.
- **Reflexión:** Esta experiencia muestra que Daniela ya practica el core del rol (disponibilidad + calidad de datos), aunque en escala menor que BCP. El desafío será escalar ese mindset a plataformas enterprise.

### STAR 2 — Construcción de base de datos compleja desde cero (SQL)
- **Situación:** Proyecto académico de Hospital DB en USF que requería modelar un sistema de información hospitalaria real.
- **Tarea:** Diseñar el modelo de datos, implementarlo en MySQL y demostrar capacidad de consulta avanzada.
- **Acción:** Creé ERD con 15+ tablas normalizadas a 3FN, escribí 40+ queries incluyendo JOINs múltiples y subconsultas para reportería clínica.
- **Resultado:** Proyecto evaluado con distinción; base técnica directamente aplicable a entornos de BI con bases de datos relacionales como Oracle/MySQL que usa BCP.
- **Reflexión:** Aunque es proyecto académico, la metodología (ERD → normalización → queries → reportería) replica exactamente el flujo de trabajo de un analista BI operacional.

### STAR 3 — Optimización de reportes ejecutivos (Power Query + Excel)
- **Situación:** La dirección de Smart Perú necesitaba reportes de productividad consolidados de múltiples fuentes de datos (asistencia, activos, incidencias).
- **Tarea:** Automatizar la consolidación para reducir esfuerzo manual y garantizar consistencia.
- **Acción:** Implementé Power Query para conectar y transformar múltiples hojas, creé tablas dinámicas con KPIs clave, y estandaricé plantillas de reporte PowerPoint para Vicepresidencia.
- **Resultado:** Proceso de consolidación pasó de manual a semi-automatizado; reportes entregados de forma consistente con menor margen de error.
- **Reflexión:** Demuestra capacidad de optimización continua — uno de los pilares explícitos del JD de BCP ("optimizar continuamente herramientas y bases de datos").

### STAR 4 — Auditoría de datos en KAT Manufacturing (Tableau)
- **Situación:** Proyecto de análisis de datos de manufactura que requería identificar inconsistencias y patrones operacionales.
- **Tarea:** Auditar 150+ registros y construir visualizaciones para comunicar hallazgos.
- **Acción:** Realicé limpieza y validación de datos, construí 10+ visualizaciones en Tableau identificando patrones de producción y anomalías.
- **Resultado:** Dashboards presentados con hallazgos accionables; portfolio de visualización que demuestra pensamiento analítico aplicado a datos operacionales.
- **Reflexión:** Para BCP, este story debe complementarse con una versión en Power BI para alinearse con el stack tecnológico del banco. Recomiendo reproducir este análisis en Power BI antes de aplicar.
